# Brew & Bean — 3D Coffee Shop Website

A fully custom coffee-shop storefront built with:
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- 3D-style animated hero coffee cup
- Scroll reveal animations
- Animated coffee/brand ticker
- Responsive menu
- Category filtering
- Add-to-cart functionality
- Quantity controls
- Custom coffee builder
- Live price calculation
- Milk, size, sweetness and extras
- Checkout/order confirmation UI
- Responsive mobile layout
- Reduced-motion accessibility support

## Run
Open `index.html` directly in Chrome/Edge/Firefox.

No build step is required.

## Customize
Edit the `menu` array near the top of `script.js` to add/change products and prices.

The checkout is a front-end demo. To accept real orders/payments, connect the form to your own backend/payment/order system.
